# 麦克纳姆轮电磁循迹小车

2024 年课程团队项目的应用代码归档，展示四轮运动控制、四路电磁传感采样与 PD 转向调参。本组件保留了现存应用快照及其局限，适合结合代码解释早期嵌入式调试经历。

本人在团队中负责任务三（PWM 电机驱动与麦克纳姆轮运动控制）、参数调节、代码完善和报告。该分工由原答辩第 24 页支持；任务三也由另一成员共同承担。整套采样与循迹算法属于团队工作，现有材料不能逐行认定作者。

## 运行主机验证

需要 Python 3 和支持 GB18030 输入字符集的 GCC：

```sh
python tests/run_host_tests.py
python tests/run_host_tests.py --cc /path/to/gcc
```

测试以无硬件副作用的 API stub 链接原始 `type.c`，生成物放系统临时目录，退出后清理。它不会执行固件 `main`、连接设备、烧录或输出真实 PWM。

本轮通过了 285 个断言（含 stub 接口断言），并通过独立子进程复现了持续超出校准上限时的循环不退出行为。这里只验证主机上的合成输入行为，未重新构建完整 STC8H 固件、未上车或复赛。

历史答辩描述了团队完成比赛及弯道、抖动、电池与电机温升等调试经历。这些是历史叙述，不能与当前源码版本逐项对应，也不作为本轮实测指标。原始报告、带成员信息的 PPT、教师课件、库和编译产物不随组件公开。

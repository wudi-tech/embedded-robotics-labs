## 完整固件边界

原 Keil 工程的第三方库引用使用 `../../Libraries/...`，在现存应用文件夹布局下缺失；另一个课程材料位置保存了库副本。本轮未复制整库、未重定位完整 Keil 工程，也未执行 C51 全固件构建。现有工具可进行主机验证，不能把历史构建文件或 GCC stub 编译称为 STC8H 固件构建成功。

工程目标名、器件字段及库注释的 STC8H 具体型号存在差异，归档只称 STC8H 平台；没有通过源码元数据确定实际板卡型号。
